      여러 기기에서 학습 기록 이어가기

      이메일 계정으로 로그인하면 Day 체크리스트·메모·퀴즈 점수·월별 진도·자격증 일정을 클라우드에 저장할 수 있어요. 노트북의 .py 파일은 여기서 동기화되지 않아요.

      연결 상태

      Supabase 연결 준비 중…

      처음 사용하는 계정은 회원가입 후 인증 메일을 확인해야 할 수 있어요. 이메일·비밀번호는 Study Planner 학습 기록에 저장하지 않아요.

      로그인 계정:

      기기마다 기록이 다르면 자동으로 덮어쓰지 않아요. 기존 학습 내용이 있는 기기에서 최초 업로드하고, 다른 기기에서는 클라우드 기록을 불러오세요. 가져올 때 기존 기기 데이터는 백업 파일로 보관할 수 있어요.

      ● 클라우드 동기화 연결됨

      이 기기에서 변경하면 자동 저장돼요. 다른 PC에서 수정한 기록은 현재 페이지를 새로고침하거나 '지금 동기화'로 확인해 주세요. 두 PC에서 동시에 수정하면 어떤 기록을 사용할지 선택해야 할 수 있어요.

      공용 PC에서는 반드시 로그아웃하고, 필요하면 브라우저의 해당 사이트 데이터를 정리하세요. 로그아웃만으로 이 기기의 기존 학습 메모가 삭제되지는 않아요.

      학습 기록 JSON 백업

      동기화 전에 현재 브라우저의 기록을 파일로 보관해 두는 것을 추천해요. 클라우드 불러오기로 기기 데이터가 교체될 때도 백업하도록 만들었어요.

      12개월 성장 로드맵

      첫 30일은 Day별 상세 학습, 이후는 월별 4주 학습 계획·자료·프로젝트로 진행합니다. 각 월을 누르면 강의와 실습을 볼 수 있어요.

      장기 목표

      Python → 백엔드·Linux → AWS·보안 자동화 → AI 서비스 보안·신뢰성. 6개월 뒤 기술직 채용요건을 점검하고 12개월째 포트폴리오를 완성하는 것이 1차 목표예요.

      로그인 전에는 브라우저(localStorage)에 저장되고, 클라우드 동기화 연결 후에는 Supabase에도 저장됩니다. 처음 연결 시 기록을 선택해야 하며, 다른 PC에서 확인하려면 같은 계정으로 로그인하세요. 브라우저 데이터를 삭제하거나 클라우드 기록을 교체하기 전에 JSON 백업을 권장합니다. 민감한 개인정보·회사 내부 자료는 기록하지 마세요.
